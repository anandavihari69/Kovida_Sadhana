# कोविदसाधना · Kovida Sādhanā

A topic-wise reader for the Samskrita Bharati **Kovida** examination, in Sanskrit and Telugu:
topics and sub-topics, the Kovida book, analysed verses, practice questions, past papers with model answers,
a whole-book सङ्ग्रहः, and a tap-any-word कोशः (dictionary).

Open `index.html` (or the GitHub Pages site) and use "Add to Home screen" to install it on a phone; it works offline after the first visit.

Kosha entries marked **Claude · अपरीक्षितम्** were written by an AI and have not been checked yet.
