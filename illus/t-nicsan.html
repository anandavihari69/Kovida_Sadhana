णिजन्ताः (णिच्)ణిజంతం · causative – "करोति → कारयति"
अर्थः · प्रेरणाఅర్థం · meaning
नियमः · నియమం · rule
प्रेरणार्थे धातोः णिच् (अय) – एकः करोति, अन्यः तं कारयति। प्रेरकः = प्रयोजककर्ता, कार्यं कुर्वन् = प्रयोज्यकर्ताప్రేరణ అర్థంలో ణిచ్ – ఒకరు చేస్తే, మరొకరు చేయిస్తారు · "make someone do": the causer is the new subject
पठति → पाठयतिచదువుతాడు → చదివిస్తాడు · reads → makes read (teaches)
हसति → हासयतिనవ్వుతాడు → నవ్విస్తాడు · laughs → makes laugh
करोति → कारयतिచేస్తాడు → చేయిస్తాడు · does → gets done

उपधा-अकारः → आ
नियमः · నియమం · rule
धातोः उपधायाम् (अन्त्यात् पूर्वम्) अ चेत् – आ (वृद्धिः) + अयచివరి ముందు అ ఉంటే ఆ · a before the last consonant becomes ā
पठ् → पाठयतिచదివిస్తాడు · makes read
वद् → वादयतिమాట్లాడిస్తాడు / వాయిస్తాడు · makes speak, plays
हस् → हासयतिనవ్విస్తాడు · makes laugh
चल् → चालयतिకదిలిస్తాడు · moves, drives
उपधा-इ / उ / ऋ → गुणः
नियमः · నియమం · rule
उपधायां लघु इ / उ / ऋ – गुणः (ए / ओ / अर्) + अयఇ→ఏ, ఉ→ఓ, ఋ→అర్ · i→e, u→o, ṛ→ar
लिख् → लेखयतिవ్రాయిస్తాడు · makes write
मिल् → मेलयतिకలుపుతాడు · brings together
दृश् → दर्शयतिచూపిస్తాడు · shows
वृत् → वर्तयतिనడిపిస్తాడు · makes go on
अन्त्यस्वरः → वृद्धिः
नियमः · నియమం · rule
स्वरान्तधातोः अन्त्यस्वरस्य वृद्धिः (ऐ / औ / आर्) + अयచివరి అచ్చుకు వృద్ధి · final vowel takes vṛddhi
कृ → कारयतिచేయిస్తాడు · gets done
श्रु → श्रावयतिవినిపిస్తాడు · makes hear, recites

भू → भावयतिభావిస్తాడు · causes to be

सन्नन्ताः (सन्)సన్నంతం · desiderative – "कर्तुम् इच्छति → चिकीर्षति"
अर्थः · इच्छाఅర్థం · meaning
नियमः · నియమం · rule
"…तुम् इच्छति" इत्यर्थे धातोः सन् (स / इष); धातोः द्वित्वम्, अभ्यासे अ → इ"చేయాలని కోరుకొను" – ధాతువు ద్విత్వం, మొదటి అక్షరంలో అ→ఇ · "wants to do" – root doubled, a→i in the first copy
